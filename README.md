# 🎯 صيّاد الأسعار — Price Hunter Egypt (v2.0)

مقارنة أسعار **حقيقية لحظية** من المتاجر المصرية — كل نتيجة تفتح صفحة المنتج نفسها على المتجر مباشرة.

## ✨ الجديد في النسخة 2.0

### 1) خلفية إلكترونيات + علامة مائية
- خلفية `bg-hero.jpg` (موبايلات وسماعات ودوائر إلكترونية بتدرّج الكحلي الغامق بتاع الثيم).
- علامة مائية **Tarek Abozaid** مRepeat على طول الصفحة (طبقة CSS خفيفة) + في الفوتر + في الطباعة/PDF.

### 2) زرار تنبيهات الأسعار (إيميل / واتساب)
- زرار ثابت فوق + زرار CTA في الهيرو + زرار عائم + زرار في الفوتر: «ابعتولي الأسعار الجديدة».
- الزائر يختار إيميل أو واتساب، يسجل بياناته → تُحفظ في `data/subscribers.json` على السيرفر (تبقى بعد إعادة التشغيل).
- نفس النظام متاح لكل منتج على حدة: «🔔 نبهني عند نزول السعر».

### 3) بحث حقيقي 100% (لا يوجد بيانات وهمية)
**متاجر بتترجع أسعار حية + روابط منتجات حقيقية:**

| المتجر | المصدر | ملاحظات |
|--------|--------|---------|
| دريم 2000 | Shopify Predictive Search API | أسعار لحظية + رابط المنتج |
| فونكس Vontx | صفحة البحث الرسمية | أسعار لحظية + رابط المنتج |
| اتصال ستور | الـ API الرسمي للموقع | أسعار لحظية + رابط المنتج |
| ميامي سنترز | WooCommerce Store API | أسعار لحظية + رابط المنتج |
| دبي فون (dubaiphone.net) | WooCommerce Store API | بيتحاول مع كل بحث؛ لو المتجر عطّله بنظهر رابط بحثه |

**متاجر بتمنع السحب المباشر من السيرفرات (bot protection):**
جوميا، نون، أمازون مصر، 2B، بي تك، رنين — للتليف: **مبنعرضش ليها منتجات وهمية أبداً**. بنعرض زراير «افتح بحث المتجر» بتفتح نتائج البحث عن نفس الكلمة عندهم فورًا (روابطهم الحقيقية).

> **ليه؟** المتاجر دي (Cloudflare/anti-bot) بتمنع السيرفرات السحابية من سحب الصفحات. أي موقع يقولك إنه بيعرض «أسعار جوميا ونون لايف من السيرفر» من غير متصفح حقيقي — غالبًا بياناته قديمة أو ملفقة.

### 4) اللينكات
- كل كارت منتج → صفحة المنتج **نفسها** على المتجر (مفيش لينكات بايظة ولا صفحات بحث).
- كل كارت عليه شارة «✅ صفحة المنتج مباشرة على المتجر» + شارة «🟢 سعر حي».
- متاجر السحب الممنوع → زرار بحث واضح ومكتوب عليه إنه بحث.

### 5) تتبع أسعاري
- أول مرة تدور على منتج بنخزن السعر اللي شفته (localStorage عندك). لو دوّرت تاني والسعر اتغير → سهم ▲/▼ + جدول «أسعاري المتتبعة» — بيانات حقيقية من بحثك.

## ☁️ الرفع على Render
1. ادخل على https://dashboard.render.com
2. New + → Web Service → Connect GitHub repo
3. الإعدادات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** `Node`
4. Deploy → انسخ رابط الموقع.

## 📡 الـ API
| Endpoint | الوصف |
|----------|-------|
| `GET /api/search?q=...` | بحث حقيقي مجمّع: نتائج حية + `storeLinks` للمتاجر المحمية |
| `GET /api/suggestions?q=...` | اقتراحات منتجات حقيقية أثناء الكتابة |
| `POST /api/subscribe` | تسجيل «ابعتولي الأسعار الجديدة» `{contact, type: email\|whatsapp, query}` |
| `GET /api/subscribers` | قائمة المسجلين (للمالك) |
| `POST /api/alerts` | تنبيه سعر لمنتج محدد |
| `GET /api/stores` · `GET /api/health` | معلومات المتاجر والحالة |
