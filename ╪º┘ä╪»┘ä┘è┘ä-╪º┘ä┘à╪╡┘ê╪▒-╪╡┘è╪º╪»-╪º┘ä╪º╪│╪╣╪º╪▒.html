الجزء الأول

1️⃣ رفع المشروع على GitHub

هنرفع الفاينال على GitHub عشان Render يسحب منه. الملف price-hunter-final.zip جاهز للفك.

الشكل 1: إنشاء Repository جديد على GitHub + Push الكود
1

فك الضغط

فك ملف price-hunter-final.zip هتلاقي: server.js + public/ + package.json + render.yaml

2

إنشاء Repo على GitHub

ادخل GitHub → New repository → الاسم: price-hunter-egypt → Public → بدون README → Create

3

رفع الكود (انسخ الأوامر)

افتح Terminal داخل مجلد المشروع:

git init
git add .
git commit -m "final: Price Hunter Egypt ready for Render"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/price-hunter-egypt.git
git push -u origin main
⚠️ بدّل YOUR_USERNAME باسم حسابك على GitHub. لو Repo موجود اعمل git push فقط.
✅ تأكد: ادخل الرابط github.com/YOUR_USERNAME/price-hunter-egypt هتشوف الملفات مرفوعة.
الجزء الثاني

2️⃣ النشر على Render — Web Service

Render هيستضيف السيرفر Node.js مجاناً. ملف render.yaml موجود لتسهيل النشر التلقائي.

الشكل 2: لوحة Render — ربط GitHub + إعدادات Build/Start
1

تسجيل دخول Render

https://dashboard.render.com → Sign in with GitHub → وافق على الصلاحيات

2

New + → Web Service

اختار Repo: price-hunter-egypt → Connect

3

الإعدادات (مهم)

Render هيقرأ render.yaml تلقائياً، أو اكتب يدوياً:

الحقلالقيمة
Nameprice-hunter-egypt
EnvironmentNode
Build Commandnpm install
Start Commandnpm start
PlanFree
4

متغيرات البيئة (Environment Variables)

Add Environment Variable → Key: DEMO_MODE → Value: false (للعرض الحي) أو true (ديمو 3 نتائج + بانر أصفر)

5

Deploy

دوس Create Web Service → انتظر 2-3 دقائق → هيطلعلك رابط https://price-hunter-egypt.onrender.com

✅ اختبر: افتح الرابط → اكتب سماعات هواوي → ابحث → لازم تشوف 27 عرض.

الجزء الخامس

5️⃣ اختبار الموقع قبل التسليم

✅ Desktop

  • افتح https://price-hunter-egypt.onrender.com → Hero يظهر + 11 متجر
  • اكتب "سماعات هواوي" → ابحث → 27 عرض + بانر أخضر "نتائج حية"
  • دوس فلتر "فونكس" → 9 عروض فقط | "اتصال ستور" → 8 عروض
  • دوس "أعلى خصم" → أول منتج خصم 22% | "أبجدي" → ترتيب A-Z
  • دوس "طباعة / PDF" → Preview نظيفة
  • غيّر اللغة EN → كل النصوص إنجليزي + Dir LTR

✅ Mobile

  • افتح على موبايل → Hero + بحث + تصنيفات عمودية
  • النتائج: كروت إحصائيات 2×2 → صفوف منتجات عمودية
  • الفلتر يعمل باللمس بدون تهنيج

✅ SEO

  • /robots.txt يفتح → /sitemap.xml يفتح
  • View Source → شوف og:title + application/ld+json
  • Google Rich Results Test → بدون أخطاء
  • Lighthouse SEO → 100/100
✅ لو كل ده نجح = الموقع جاهز 100% للتسليم والـ Deploy
